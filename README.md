# Daily Concepts

One note a day on random matrix theory, high-dimensional probability, covariance estimation, regression &
shrinkage, and uncertainty quantification. Built with MkDocs Material.

## Run locally

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/mkdocs serve          # http://127.0.0.1:8000
```

## Publish on GitHub Pages

1. Create a GitHub repository (e.g. `daily-concepts`) and push this folder to its `main` branch.
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Every push to `main` rebuilds and deploys to `https://<user>.github.io/<repo>/`.
4. Optionally set `site_url` in `mkdocs.yml` to that address.

Reading progress (which notes you've seen, today's note) is stored in your browser's localStorage,
so each device keeps its own progress.

## Adding notes

Notes live in `docs/notes/<slug>.md`, with slugs and prerequisites defined in `curriculum.yml`.
A note appears in the sidebar and daily rotation as soon as its file exists. Figures are generated by
`scripts/figures/<slug>.py` (`pip install -r requirements-figures.txt`).
