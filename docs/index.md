# Daily Concepts

One note a day on random matrix theory, high-dimensional probability, covariance estimation,
regression & shrinkage, and uncertainty quantification. These are the tools behind modern ML theory and quantitative finance.

## How the notes are built

Each note starts with **why the idea matters**, builds up from the basics to the **main result**
(stated precisely, with a derivation or proof sketch), works through **examples and simulations**,
ends with **exercises** (tap to reveal solutions), and closes with **applications** in modern ML and quant
when it makes sense.

**Background assumed:** multivariable calculus, linear algebra, basic probability & statistics.

## How the daily note works

- **Daily note** gives you the next unread note. The order respects prerequisites and alternates between tracks.
- You get the same note for the whole day. A new one is picked tomorrow.
- Opening any note from the sidebar also marks it read, so the daily cycle won't show it again
  until you have seen everything. Use the button at the bottom of a note to mark it unread.
- Progress is stored in your browser (see [Progress](progress.md)). The full plan is on the [Roadmap](roadmap.md).
